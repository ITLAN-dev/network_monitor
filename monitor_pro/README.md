# 🛰️ Monitor PRO

**Расширенный мониторинг TIME_WAIT, памяти, CPU и процессов для Windows**

[![Python Version](https://img.shields.io/badge/python-3.6+-blue.svg)](https://python.org)
[![Platform](https://img.shields.io/badge/platform-Windows-blue.svg)](https://microsoft.com/windows)
[![License](https://img.shields.io/badge/license-MIT-green.svg)](LICENSE)

**Monitor PRO** — инструмент для диагностики сетевых проблем, утечек памяти и высокой нагрузки на CPU.

Помогает выявлять:

* 🔌 Исчерпание портов (`TIME_WAIT`)
* 💾 Утечки памяти в процессах
* 💻 Высокую загрузку CPU
* 🌐 Проблемы с сетью (DDoS, ошибки NIC)
* 🔄 Использование SWAP

## 🚀 Возможности

### Основные метрики

* ✅ **TIME_WAIT** — количество соединений в состоянии ожидания закрытия
* ✅ **Скорость сети** — отправка/получение в Мбит/с
* ✅ **Пакеты в секунду (PPS)** — интенсивность трафика
* ✅ **Ошибки сети** — ошибки на уровне драйвера/NIC
* ✅ **Потерянные пакеты** — переполнение буферов

### Расширенные метрики (PRO)

* ✅ **Память по процессам** — RSS, VMS для ТОП-5 процессов
* ✅ **CPU по процессам** — реальная загрузка для каждого процесса
* ✅ **CPU системы** — средняя нагрузка, нагрузка по ядрам, Load Average
* ✅ **Контекстные переключения** — диагностика проблем с драйверами
* ✅ **Тренды метрик** — анализ изменений за последние N секунд
* ✅ **Автоматическая диагностика** — 8 типов проблем с версиями
* ✅ **Сохранение снапшотов** — JSON для анализа в Grafana/ELK

### Режимы работы

* **Вербозный (`-v`)** — полная статистика на каждой итерации
* **Тихий (по умолчанию)** — только предупреждения и статус раз в минуту
* **Максимально тихий (`-q`)** — только критические ошибки

## 📦 Установка

### 1. Установите Python 3.6+

Скачайте и установите Python с официального сайта:

👉 [python.org/downloads/windows/](https://www.python.org/downloads/windows/)

> **Важно:** при установке обязательно установите флажок **Add Python to PATH**.

Проверьте установку:

```bash
python --version
```

### 2. Установите зависимость

```bash
python -m pip install psutil
```

### 3. Скачайте скрипт

Сохраните скрипт как `monitor_pro.py` в удобную папку.

## 🏃 Быстрый старт

### Базовый запуск (тихий режим)

```bash
python monitor_pro.py
```

### Вербозный режим

```bash
python monitor_pro.py -v
```

### Для сервера с 32 ГБ RAM и гигабитной сетью

```bash
python monitor_pro.py -v -t 15000 -w 8000 -m 4096 -mw 2048 -n 950 -nw 700
```

### Сохранение лога и снапшотов

```bash
python monitor_pro.py -v -l monitor.log -s ./snapshots
```

## ⚙️ Аргументы командной строки

### Пороги TIME_WAIT

| Аргумент          | По умолчанию | Описание                          |
| ----------------- | -----------: | --------------------------------- |
| `-t, --threshold` |       `1000` | Критический порог TIME_WAIT       |
| `-w, --warning`   |        `500` | Предупредительный порог TIME_WAIT |

### Пороги сети (Мбит/с)

| Аргумент                  | По умолчанию | Описание                        |
| ------------------------- | -----------: | ------------------------------- |
| `-n, --network-threshold` |        `950` | Критическая скорость сети       |
| `-nw, --network-warning`  |        `700` | Предупредительная скорость сети |

### Пороги памяти (МБ)

| Аргумент              | По умолчанию | Описание                              |
| --------------------- | -----------: | ------------------------------------- |
| `-m, --mem-threshold` |       `1024` | Критический размер RSS процесса       |
| `-mw, --mem-warning`  |        `512` | Предупредительный размер RSS процесса |

### Пороги CPU (%)

| Аргумент              | По умолчанию | Описание                       |
| --------------------- | -----------: | ------------------------------ |
| `-c, --cpu-threshold` |         `80` | Критическая загрузка CPU       |
| `-cw, --cpu-warning`  |         `60` | Предупредительная загрузка CPU |

### Общие параметры

| Аргумент             | По умолчанию | Описание                            |
| -------------------- | -----------: | ----------------------------------- |
| `-i, --interval`     |        `2.0` | Интервал проверки в секундах        |
| `-l, --log-file`     |       `None` | Путь к файлу для сохранения лога    |
| `-s, --snapshot-dir` |  `snapshots` | Директория для сохранения снапшотов |
| `--no-snapshots`     |      `False` | Отключить сохранение снапшотов      |
| `-v, --verbose`      |      `False` | Вербозный режим (показывать всё)    |
| `-q, --quiet`        |      `False` | Максимально тихий режим             |

### Дополнительные параметры

| Аргумент            | По умолчанию | Описание                                         |
| ------------------- | -----------: | ------------------------------------------------ |
| `--top`             |          `5` | Количество ТОП-процессов для отображения         |
| `--trend-window`    |         `60` | Размер окна для трендов в секундах               |
| `--alert-cooldown`  |         `60` | Интервал между повторными предупреждениями (сек) |
| `--status-interval` |         `60` | Интервал вывода статуса в тихом режиме (сек)     |

## 📝 Примеры использования

### 1. Для веб-сервера (Nginx, Apache)

```bash
python monitor_pro.py -v -t 15000 -w 8000 -m 4096 -mw 2048 -c 80 -cw 65
```

### 2. Для базы данных (PostgreSQL, MySQL)

```bash
python monitor_pro.py -v -t 5000 -w 2000 -m 8192 -mw 4096 -c 70 -cw 50
```

### 3. Для разработчика (локальная машина)

```bash
python monitor_pro.py -v -t 500 -w 200 -m 2048 -mw 1024 -c 50 -cw 40
```

### 4. Только мониторинг памяти (отключить сеть)

```bash
python monitor_pro.py -v -n 9999 -nw 9999 -m 2048 -mw 1024
```

### 5. Фоновый мониторинг с логом

```bash
python monitor_pro.py -q -l monitor.log --alert-cooldown 300
```

### 6. Полный анализ с сохранением всех данных

```bash
python monitor_pro.py -v \
  -t 15000 -w 8000 \
  -n 850 -nw 600 \
  -m 4096 -mw 2048 \
  -c 80 -cw 65 \
  -i 2 \
  --alert-cooldown 120 \
  --status-interval 30 \
  --trend-window 120 \
  --top 10 \
  -l full_monitor.log \
  -s ./snapshots
```

## 🔍 Диагностика проблем

### Какие проблемы помогает выявить

| Проблема                  | Признак в выводе                                                         |
| ------------------------- | ------------------------------------------------------------------------ |
| **Исчерпание портов**     | `TIME_WAIT > порога`, сообщение о процессе-виновнике                     |
| **Утечка памяти**         | Процесс растёт более чем на 20% за `--trend-window`                      |
| **DDoS-атака**            | Один хост создаёт более 100 `TIME_WAIT` или более 30% от всех соединений |
| **Переполнение буфера**   | Рост ошибок и потерь при высокой скорости                                |
| **Нехватка RAM**          | Использование SWAP более 1 ГБ                                            |
| **Проблемы с драйверами** | Более 1 млрд контекстных переключений                                    |
| **Проблемы с NIC**        | Более 1000 ошибок сети                                                   |

### Расшифровка статусов

| Статус                | Значение                                                    |
| --------------------- | ----------------------------------------------------------- |
| 🟢 **НОРМАЛЬНЫЙ**     | Все метрики в пределах нормы                                |
| 🟡 **ПРЕДУПРЕЖДЕНИЕ** | Одна или несколько метрик превысили предупредительный порог |
| 🔴 **КРИТИЧЕСКИЙ**    | Одна или несколько метрик превысили критический порог       |

## 🛠️ Устранение неполадок

### CPU показывает `0.0%`

**Причина:** процессы неактивны в момент замера.

**Решение:** это нормально. Если процессы активны, CPU будет показывать значение выше `0%`. Для точности используется интервал в 1 секунду.

### Ошибка: `psutil` не установлен

Установите библиотеку:

```bash
python -m pip install psutil
```

### Ошибка доступа к процессам

Запустите скрипт с правами администратора.

1. Нажмите **Win + X**.
2. Выберите **Терминал (Администратор)**.
3. Запустите:

```bash
python monitor_pro.py
```

### Скрипт не видит сетевые интерфейсы

Проверьте, что у вас есть активное сетевое подключение.

Скрипт использует:

```python
psutil.net_io_counters()
```
